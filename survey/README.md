# Survey data (n = 11)

Anonymised responses to the pre-deployment needs survey administered on
19 November 2026. Personally identifying fields (timestamps, names, emails)
have been removed. See the paper (Section 8) for analysis.

Column mapping (Spanish → English):

| Column | English |
|---|---|
| areas_academicas | Academic areas of the courses taught |
| tipos_preguntas | Question types in the platform |
| num_preguntas | Average questions per quiz |
| num_cuestionarios | Quizzes reviewed per period |
| revisa_individual | Reviews each answer individually? |
| metodo_calificacion | How grades are assigned |
| feedback_correctas | Provides feedback on correct answers? |
| feedback_incorrectas | Provides feedback on incorrect answers? |
| criterios_abiertas | Criteria for open-ended answers |
| detalle_revision | Depth of review |
| evita_actualizar | Avoids updating quizzes for auto-grading |
| evita_abiertas | Avoids open-ended questions |
| carga_excesiva | Perceives grading as time-consuming |
| tedio | Perceived tedium (1–5) |
| dificultad | Main difficulties |
| tiempo_por_cuestionario | Time per quiz |
| limita_tiempo | Grading limits other activities |
| usa_herramientas | Uses any tool |
| describe_herramienta | Free-text description |
| disposicion | Willingness to use an LLM grader |
| funcionalidades | Requested features |
| autonomia | Desired autonomy level |
| preocupacion | Primary concern |
| confianza | Trust level (1–5) |
| frecuencia_actualizacion | How often grades are updated |
